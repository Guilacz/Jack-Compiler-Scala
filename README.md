# Jack Compiler in Scala

A compiler and VM translator for the Jack programming language, implemented in Scala as an academic project.

The project was developed progressively through several stages, covering different parts of the compilation process.

## 🔍 Project Overview

The project implements key components of a compiler, transforming Jack source code through multiple stages toward executable VM instructions.

It was developed as a collaborative academic project and provided practical experience with parsing, lexical analysis, symbol management and code generation.

## ⚙️ Main Components

### Tokenizer
Performs lexical analysis of Jack source code and identifies tokens such as keywords, identifiers, symbols, integers and strings.

### Compilation Engine
Parses the tokenized source code and processes the grammatical structure of the Jack language.

### Symbol Table
Tracks variables, their types, scope and indexes during compilation.

### VM Writer
Generates VM instructions from the compiled Jack source code.

### VM Translator
Processes VM commands as part of the translation pipeline.
